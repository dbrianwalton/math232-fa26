    Worksheet Exponential Functions and Logarithmic Differentiation
    

    Objectives

    • Build a logarithmic scale by placing each number \(y\) at the position \(x=\ln(y)\text{,}\) and explain why multiplying \(y\) by a fixed number shifts its position by a fixed distance.
      🔗
      🔗
    • Use the continuity of \(\ln\) to explain why there is a number \(e\) with \(\ln(e)=1\text{,}\) and why every real number is a value of \(\ln\text{.}\)
      🔗
      🔗
    • Define \(e^p\) and \(b^p\) for every real power \(p\) by the equations \(\ln(e^p)=p\) and \(\ln(b^p)=p\ln(b)\text{,}\) and check that these definitions agree with integer powers.
      🔗
      🔗
    • Differentiate \(\ln(e^x)=x\) and \(\ln(b^x)=x\ln(b)\) to show that \(\dfrac{d}{dx}\big[e^x\big]=e^x\) and \(\dfrac{d}{dx}\big[b^x\big]=b^x\ln(b)\text{.}\)
      🔗
      🔗
    • Use logarithmic differentiation to prove the power rule for every real power and to recover the product rule.
      🔗
      🔗
    • Use logarithmic differentiation to differentiate functions such as \(x^x\text{,}\) where neither the power rule nor the exponential rule applies.
      🔗
      🔗
    🔗
    We know a lot about \(\ln(x)\text{:}\) it is defined by an integral, it turns products into sums, and its derivative is \(1/x\text{.}\) Today we use \(\ln\) to make sense of powers \(b^p\) when \(p\) is not a whole number, and then to find their derivatives. Throughout, you may use the approximate values
    \begin{equation*} \ln(2)\approx 0.693 \qquad\text{and}\qquad \ln(3)\approx 1.099\text{.} \end{equation*}
    🔗
    Team Roles: Manager, Recorder, Spokesperson, and Reflector.
    🔗

    1. Building a Logarithmic Scale.

    On the number line below, each position \(x\) is marked underneath. We will write a number \(y\) above the line at the position \(x=\ln(y)\text{.}\) Since \(\ln(1)=0\text{,}\) the label \(y=1\) has already been placed above \(x=0\text{.}\)
    🔗

    (a)

    Use the power rule for logarithms to find the position \(x=\ln(y)\) for \(y=2\text{,}\) \(4\text{,}\) and \(8\text{.}\) Label each of these values of \(y\) above the number line. How far apart are consecutive labels?
    🔗
    🔗

    (b)

    Now find the positions for \(y=\frac{1}{2}\text{,}\) \(\frac{1}{4}\text{,}\) and \(\frac{1}{8}\text{,}\) and label them. On which side of \(x=0\) do they fall, and why?
    🔗
    🔗

    (c)

    Label \(y=3\text{,}\) \(y=6\text{,}\) and \(y=9\) on the number line. Starting from any label \(y\text{,}\) what happens to \(y\) when you move a distance \(\ln(3)\) to the right? What happens when you move a distance \(\ln(3)\) to the left?
    🔗
    🔗

    (d)

    Is there a number \(y\) that belongs above the position \(x=1\text{?}\) Between which two labels must it be? Use the fact that \(\ln\) is continuous to explain why such a number must exist.
    🔗
    🔗
    🔗

    2. Does the Scale Reach Every Position?

    (a)

    Find a power of \(2\) whose label sits to the right of \(x=10\text{,}\) and a power of \(2\) whose label sits to the left of \(x=-10\text{.}\) Explain why there must be a number \(y\) with \(\ln(y)=10\) and a number \(y\) with \(\ln(y)=-10\text{.}\) Would the same reasoning work for any position \(p\) on the number line?
    🔗
    🔗
    🔗

    Remark 57 The Range of \(\ln\).

    Because \(\ln'(x)=\dfrac{1}{x}\gt 0\text{,}\) the function \(\ln\) is increasing, so no two numbers \(y\) are ever placed at the same position. Because \(\ln(2^n)=n\ln(2)\) can be made as large or as negative as we like, and \(\ln\) is continuous, every position is filled. In other words, the range of \(\ln\) is \((-\infty,\infty)\text{,}\) and for every real number \(p\) there is exactly one \(y\gt 0\) with \(\ln(y)=p\text{.}\)
    🔗
    🔗

    Definition 58 The Number \(e\) and Real Powers.

    The natural base \(e\) is the number with \(\ln(e)=1\text{.}\)
    🔗
    For every real number \(p\text{,}\) the power \(e^p\) is the number with
    \begin{equation*} \ln(e^p)=p\text{.} \end{equation*}
    More generally, if \(b\gt 0\text{,}\) the power \(b^p\) is the number with
    \begin{equation*} \ln(b^p)=p\ln(b)\text{.} \end{equation*}
    The natural exponential function is \(\exp(x)=e^x\text{,}\) and the exponential function with base \(b\) is \(\exp_b(x)=b^x\text{.}\)
    🔗
    🔗

    3. Does the Definition Agree with What We Know?

    (a)

    Using the definition, \(e^3\) is the number whose logarithm is \(3\text{.}\) Use the product rule for logarithms to find \(\ln(e\cdot e\cdot e)\text{.}\) Explain why the definition gives the same number \(e^3\) as multiplying \(e\) by itself three times.
    🔗
    🔗
    🔗

    Theorem 59 \(e^x\) and \(\ln(x)\) Are Inverse Functions.

    For every real number \(x\text{,}\) \(\ln(e^x)=x\text{,}\) and for every \(y\gt 0\text{,}\) \(e^{\ln(y)}=y\text{.}\) Since \(\ln\) is differentiable and its derivative \(1/y\) is never zero, its inverse function \(e^x\) is also differentiable. For the same reason, \(b^x\) is differentiable for every \(b\gt 0\text{.}\)
    🔗
    🔗

    4. Derivatives of Exponential Functions.

    Now that we know \(e^x\) and \(b^x\) have derivatives, we can find them by differentiating the equations that define them, just as in implicit differentiation.
    🔗

    (a)

    Differentiate both sides of \(\ln(e^x)=x\) with respect to \(x\text{.}\) Use the chain rule on the left side. Solve the result for \(\dfrac{d}{dx}\big[e^x\big]\text{.}\)
    🔗
    🔗

    (b)

    Let \(b\gt 0\text{.}\) Differentiate both sides of \(\ln(b^x)=x\ln(b)\) with respect to \(x\text{,}\) and solve for \(\dfrac{d}{dx}\big[b^x\big]\text{.}\) What is special about \(b=e\text{?}\)
    🔗
    🔗

    (c)

    The value \(b^x\) is always positive. Use the sign of \(\ln(b)\) to decide whether \(b^x\) is increasing, decreasing, or constant when \(b\gt 1\text{,}\) when \(0\lt b\lt 1\text{,}\) and when \(b=1\text{.}\) Do your answers match what you expect for \(2^x\text{,}\) \(\left(\frac{1}{2}\right)^x\text{,}\) and \(1^x\text{?}\)
    🔗
    🔗
    🔗

    Remark 60 Logarithmic Differentiation.

    In the last exercise we found a derivative by taking the logarithm first. This works for any differentiable function \(y=f(x)\) wherever \(f(x)\ne 0\text{.}\) Write \(\ln|y|=\ln|f(x)|\text{,}\) use the properties of \(\ln\) to expand the right side, and differentiate both sides. Since \(\dfrac{d}{dx}\big[\ln|y|\big]=\dfrac{y'}{y}\text{,}\) we can solve for \(y'\text{:}\)
    \begin{equation*} y' = y\cdot\frac{d}{dx}\Big[\ln|f(x)|\Big]\text{.} \end{equation*}
    This method is called logarithmic differentiation.
    🔗
    🔗

    5. What Logarithmic Differentiation Proves.

    (a)

    Let \(p\) be any real number and let \(y=x^p\) for \(x\gt 0\text{.}\) Use logarithmic differentiation to find \(y'\text{.}\) In Calculus I, the power rule was justified only for certain kinds of powers \(p\text{.}\) Why does this argument work for every real number \(p\text{,}\) such as \(p=\sqrt{2}\) or \(p=\pi\text{?}\)
    🔗
    🔗

    (b)

    Let \(y=f(x)\,g(x)\text{,}\) where \(f\) and \(g\) are differentiable and nonzero. Use logarithmic differentiation to find \(y'\text{,}\) and simplify. Which rule have you found?
    🔗
    🔗
    🔗
