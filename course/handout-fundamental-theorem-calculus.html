    Worksheet The Fundamental Theorem of Calculus
    

    Objectives

    • Accumulation functions are functions and we can write \(A(x)\text{.}\)
      🔗
      🔗
    • For the examples we have seen thus far, if we compute the accumulation function \(A(x)\) belonging to a polynomial \(p(x)\) and then compute its derivative \(A'(x)\text{,}\) we discover \(A'(x) = p(x)\text{.}\)
      🔗
      🔗
    • This means \(A(x)\) is called an antiderivative of \(p(x)\text{.}\)
      🔗
      🔗
    • The Fundamental Theorem of Calculus says this will always happen. Every continuous function \(f(x)\) will have an accumulation function \(A(x)\) and \(A'(x)=f(x)\text{.}\) Every accumulation function is an antiderivative where \(f(x)\) is continuous.
      🔗
      🔗
    • Apply the Fundamental Theorem of Calculus directly to find \(A'(x)\) for an accumulation function \(A(x) = \int_a^x f(t)\,dt\) built from a simple algebraic function \(f\text{.}\)
      🔗
      🔗
    • Rewrite a definite integral whose upper and lower limits are both formulas in \(x\) as a difference \(A(u_2)-A(u_1)\text{,}\) and use the chain rule together with the Fundamental Theorem of Calculus to differentiate it.
      🔗
      🔗
    🔗

    1. Practice: Differentiating Accumulation Functions.

    The Fundamental Theorem of Calculus tells us that if \(\displaystyle A(x) = \int_a^x f(t)\,dt\text{,}\) then \(A'(x) = f(x)\text{,}\) no matter what the lower limit \(a\) is and without ever finding a formula for \(A(x)\) itself. For each accumulation function below, use the theorem directly to find \(A'(x)\text{.}\)
    🔗

    (a)

    For \(\displaystyle A(x) = \int_0^x (2t+3)\,dt\text{,}\) find \(A'(x)\text{.}\)
    🔗
    🔗

    (b)

    For \(\displaystyle A(x) = \int_{-3}^x (t^2-4t)\,dt\text{,}\) find \(A'(x)\text{.}\)
    🔗
    🔗

    (c)

    For \(\displaystyle A(x) = \int_1^x \sqrt{t}\,dt\text{,}\) find \(A'(x)\text{.}\)
    🔗
    🔗

    (d)

    For \(\displaystyle A(x) = \int_4^x (5-t^3)\,dt\text{,}\) find \(A'(x)\text{.}\)

    2. Definite Integrals with Two Variable Limits.

    So far every accumulation function has had a fixed lower limit and \(x\) itself as the upper limit. Now suppose both limits of integration are formulas in \(x\text{,}\) say \(u_1(x)\) and \(u_2(x)\text{,}\) instead of \(x\) alone. Using the same splitting property of definite integrals we relied on earlier, and an accumulation function \(\displaystyle A(x) = \int_a^x f(t)\,dt\) for a convenient fixed \(a\text{,}\) we can write
    \begin{equation*} \int_{u_1(x)}^{u_2(x)} f(t)\,dt = A(u_2(x)) - A(u_1(x))\text{.} \end{equation*}
    You do not need a formula for \(A\) itself to write an integral this way.
    🔗

    (a)

    Rewrite \(\displaystyle \int_{x}^{x^3} (2t+3)\,dt\) in the form \(A(u_2)-A(u_1)\text{,}\) identifying \(u_1\) and \(u_2\text{.}\)
    🔗
    🔗

    (b)

    Rewrite \(\displaystyle \int_{x^2}^{2x+1} (t^2-4t)\,dt\) in the form \(A(u_2)-A(u_1)\text{,}\) identifying \(u_1\) and \(u_2\text{.}\)
    🔗
    🔗

    (c)

    Rewrite \(\displaystyle \int_{4x}^{x^2} \sqrt{t}\,dt\) in the form \(A(u_2)-A(u_1)\text{,}\) identifying \(u_1\) and \(u_2\text{.}\)
    🔗
    🔗

    (d)

    Rewrite \(\displaystyle \int_{x}^{3x} (5-t^3)\,dt\) in the form \(A(u_2)-A(u_1)\text{,}\) identifying \(u_1\) and \(u_2\text{.}\)
    🔗
    🔗
    🔗

    Remark 34. Differentiating Through the Chain Rule.

    Rewriting an integral as \(A(u_2)-A(u_1)\) is progress, but \(A(u_2)\) and \(A(u_1)\) are not simply \(A\) evaluated at \(x\text{.}\) They are \(A\) composed with the functions \(u_2(x)\) and \(u_1(x)\text{,}\) so differentiating either one requires the chain rule. Since \(A'(x) = f(x)\text{,}\) the chain rule gives
    \begin{equation*} \frac{d}{dx}\big[A(u_2)\big] = A'(u_2)\cdot u_2' = f(u_2)\cdot u_2' \end{equation*}
    and
    \begin{equation*} \frac{d}{dx}\big[A(u_1)\big] = A'(u_1)\cdot u_1' = f(u_1)\cdot u_1'\text{.} \end{equation*}
    Putting the two pieces together,
    \begin{equation*} \frac{d}{dx}\left[\int_{u_1(x)}^{u_2(x)} f(t)\,dt\right] = f(u_2)\cdot u_2' - f(u_1)\cdot u_1'\text{.} \end{equation*}
    🔗
    🔗

    3. Practice: Differentiating with Two Variable Limits.

    Return to the four integrals from the previous exercise. For each one, use \(\displaystyle \frac{d}{dx}\left[\int_{u_1(x)}^{u_2(x)} f(t)\,dt\right] = f(u_2)\cdot u_2' - f(u_1)\cdot u_1'\) to find the derivative.
    🔗

    (a)

    Find \(\displaystyle \frac{d}{dx}\left[\int_{x}^{x^3} (2t+3)\,dt\right]\text{.}\)
    🔗
    🔗

    (b)

    Find \(\displaystyle \frac{d}{dx}\left[\int_{x^2}^{2x+1} (t^2-4t)\,dt\right]\text{.}\)
    🔗
    🔗

    (c)

    Find \(\displaystyle \frac{d}{dx}\left[\int_{4x}^{x^2} \sqrt{t}\,dt\right]\text{.}\) (Assume \(x>0\text{,}\) so \(\sqrt{x^2}=x\text{.}\))
    🔗
    🔗

    (d)

    Find \(\displaystyle \frac{d}{dx}\left[\int_{x}^{3x} (5-t^3)\,dt\right]\text{.}\)
    🔗
    🔗
    🔗
    This discussion will be more theoretical in order to reach the fundamental theorem of calculus. We start by looking at a pattern in our accumulation functions.
    \begin{align*} p(x) = 1 \quad \amp \Rightarrow \quad A(b) = \int_0^b 1 \,dx = b \\ p(x) = x \quad \amp \Rightarrow \quad A(b) = \int_0^b x \,dx = \frac{1}{2}b^2 \\ p(x) = x^2 \quad \amp \Rightarrow \quad A(b) = \int_0^b x^2 \,dx = \frac{1}{3}b^3 \\ p(x) = x^3 \quad \amp \Rightarrow \quad A(b) = \int_0^b x^3 \,dx = \frac{1}{4}b^4 \end{align*}
    For each of these accumulation functions, we have used \(b\) as the ending end point of the definite integral. Once the function is identified, we can use any variable such as \(A(x)\text{.}\)
    🔗
    What happens if we now compute the derivatives of the accumulation functions?
    \begin{align*} p(x) = 1 \quad \amp \Rightarrow \quad A(x) = x \quad \Rightarrow \quad A'(x) = 1 \\ p(x) = x \quad \amp \Rightarrow \quad A(x) = \frac{1}{2} x^2 \quad \Rightarrow \quad A'(x) = \frac{1}{2}(2x) = x \\ p(x) = x^2 \quad \amp \Rightarrow \quad A(x) = \frac{1}{3}x^3 \quad \Rightarrow \quad A'(x) = \frac{1}{3}(3x^2) = x^2 \\ p(x) = x^3 \quad \amp \Rightarrow \quad A(x) = \frac{1}{4}x^4 \quad \Rightarrow \quad A'(x) = \frac{1}{4}(4x^3) = x^3 \end{align*}
    In each of these cases, we discovered \(A'(x) = p(x)\text{.}\)
    🔗
    The Fundamental Theorem of Calculus tells us this behavior is to be expected.
    🔗

    Theorem 35. The Fundamental Theorem of Calculus.

    If \(f(x)\) is continuous and has an accumulation function
    \begin{equation*} A(x) = \int_a^x f(t) \, dt \end{equation*}
    then \(A'(x) = f(x)\text{.}\)
    🔗
    In other words, an accumulation function \(A(x)\) is an antiderivative of \(f(x)\text{.}\)
    🔗
    🔗
    Here is an outline of the argument.
    • Using a variable \(x\) as the input for the accumulation function requires changing the variable of integration:
      \begin{equation*} A(x) = \int_a^x f(t) \, dt \end{equation*}
      🔗
      🔗
    • We can then use the definition of the derivative:
      \begin{equation*} A'(x) = \lim_{h \to 0} \frac{A(x+h)-A(x)}{h}. \end{equation*}
      Subtracting \(A(x+h)-A(x)\) uses the splitting property of definite integrals to give
      \begin{equation*} A(x+h)-A(x) = \int_{x}^{x+h} f(t) \, dt \end{equation*}
      🔗
      🔗
    • When \(f(t)\) is continuous on \([x,x+h]\text{,}\) there must be both a maximum value \(f_{\mathrm{max}}\) and a minimum value \(f_{\mathrm{min}}\) because of the Extreme Value Theorem. This means:
      \begin{equation*} f_{\mathrm{min}} \cdot h \le A(x+h)-A(x) \le f_{\mathrm{max}} \cdot h \end{equation*}
      🔗
      Again using continuity, by the Intermediate Value Theorem, there must be some actual value \(t^*\) between \(x\) and \(x+h\) such that \(A(x+h)-A(x) = f(t^*) \cdot h\text{.}\) That value \(t^*\) depends on \(h\text{,}\) which we write \(t^*(h)\text{.}\)
      🔗
      🔗
    • Using the limit, since \(t^*(h) \to x\) and \(f(x)\) is continuous, we must have \(A'(x) = f(x)\text{.}\)
      🔗
      🔗
    🔗

    Remark 36.

    Note that we don’t need to know the formula for \(A(x)\) in order to know the derivative’s formula \(A'(x) = f(x)\text{.}\)
