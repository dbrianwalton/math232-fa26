    Worksheet Antiderivatives and a New Kind of Function
    

    Objectives

    • Recall the definition of an antiderivative, and generalize the pattern already seen in known accumulation functions to propose and verify a formula for an antiderivative of \(f(x)=x^n\text{,}\) for \(n\ne -1\text{.}\)
      🔗
      🔗
    • Recognize that adding a constant to an antiderivative produces another antiderivative, and that any two antiderivatives of the same function on an interval must differ by a constant.
      🔗
      🔗
    • Use indefinite integral notation, \(\displaystyle\int f(x)\,dx = F(x)+C\text{,}\) to describe the entire family of antiderivatives of \(f(x)\) rather than a single one.
      🔗
      🔗
    • Identify why the power-rule pattern for antiderivatives breaks down at \(f(x)=x^{-1}=\frac{1}{x}\text{.}\)
      🔗
      🔗
    • Use the Fundamental Theorem of Calculus to construct a new function, the natural logarithm \(\displaystyle\ln(x) = \int_1^x \frac{1}{t}\,dt\text{,}\) as an antiderivative of \(1/x\text{,}\) and reason directly from this definition about its value at \(x=1\) and its domain.
      🔗
      🔗
    🔗
    On the last activity, the Fundamental Theorem of Calculus told you that every accumulation function is an antiderivative of the function it accumulates. Today we turn that idea around. Instead of starting with a function and building its accumulation function through a limit, can we start with a function \(f(x)\) and simply propose a formula whose derivative is \(f(x)\text{,}\) directly, with no limit at all?
    🔗

    Definition 37. Antiderivative.

    Given a function \(f(x)\text{,}\) another function \(F(x)\) is called an antiderivative of \(f(x)\) if \(F'(x) = f(x)\text{.}\)
    🔗
    🔗

    Remark 38. Recall: Antiderivatives You Have Already Found.

    Every accumulation function you have built so far is an example:
    \begin{align*} f(x) = 1 \quad \amp \Rightarrow \quad F(x) = x\\ f(x) = x \quad \amp \Rightarrow \quad F(x) = \frac{1}{2}x^2\\ f(x) = x^2 \quad \amp \Rightarrow \quad F(x) = \frac{1}{3}x^3\\ f(x) = x^3 \quad \amp \Rightarrow \quad F(x) = \frac{1}{4}x^4 \end{align*}
    Each of these is a single power of \(x\text{,}\) but we have not stated a single rule that covers every power at once.
    🔗
    🔗

    1. Generalizing the Power Rule.

    Look for the pattern connecting each \(f(x)\) above to its antiderivative \(F(x)\text{,}\) and use it to make a prediction for a general power \(f(x)=x^n\text{.}\)
    🔗

    (a)

    What pattern would you predict for an antiderivative of \(f(x) = x^n\text{?}\)
    🔗
    🔗

    (b)

    Write your proposal for \(F(x)\) and directly compute \(F'(x)\) using derivative rules. Is your proposal an antiderivative of \(x^n\text{?}\) If not, adjust it until \(F'(x)=x^n\text{.}\)
    🔗
    🔗
    🔗

    Remark 39. A Domain Caveat.

    Our accumulation functions were built as integrals starting at \(0\text{.}\) That definition breaks down for negative powers, such as \(f(x)=x^{-2}\text{,}\) because \(f\) has a discontinuity at \(x=0\text{:}\) an integral like \(\int_0^b x^{-2}\,dx\) simply does not exist. The antiderivative formula you just found is still perfectly good as a function in its own right, though. It just needs to be considered on an interval that avoids \(x=0\text{,}\) rather than being built as an accumulation function starting from \(0\text{.}\)
    🔗
    🔗

    2. Adding a Constant.

    Antiderivatives are not to be unique. This exercise asks you to see why, and to practice using the power rule.
    🔗

    (a)

    Suppose \(F(x)\) is an antiderivative of \(f(x)\text{,}\) and let \(C\) be any constant. Form \(G(x) = F(x)+C\) and compute \(G'(x)\text{.}\) Is \(G(x)\) also an antiderivative of \(f(x)\text{?}\) How many antiderivatives does a single function \(f(x)\) actually have?
    🔗
    🔗

    (b)

    Using the pattern from the previous exercise, write down at least three different antiderivatives of \(f(x) = x^5\text{.}\)
    🔗
    🔗

    (c)

    Do the same for \(f(x) = \sqrt{x}\text{.}\) (Rewrite \(\sqrt{x}\) as a power of \(x\) first.)
    🔗
    🔗
    🔗

    Theorem 40. Antiderivatives Differ Only By a Constant.

    If \(F(x)\) and \(G(x)\) are both antiderivatives of the same function \(f(x)\) on an interval \([a,b]\text{,}\) then \(F(x)-G(x)\) is a constant on that interval.
    🔗
    🔗

    Remark 41.

    Put together with the previous exercise, this theorem says once you know one antiderivative \(F(x)\) of \(f(x)\text{,}\) you know all of them: every antiderivative of \(f(x)\) has the form \(F(x)+C\) for some constant \(C\text{.}\) There are no other antiderivatives that aren’t captured by this family.
    🔗
    🔗

    Definition 42. The Indefinite Integral.

    The notation \(\displaystyle\int f(x)\,dx\text{,}\) an integral written with no limits of integration, is called an indefinite integral. It represents the entire family of antiderivatives of \(f(x)\text{,}\) not a single function and not a number. Once one antiderivative \(F(x)\) is found, every other antiderivative is obtained by adding a constant, so we write
    \begin{equation*} \int f(x)\,dx = F(x) + C\text{,} \end{equation*}
    where \(C\text{,}\) the constant of integration, is a placeholder for any real number. This is different from the definite integral \(\int_a^b f(x)\,dx\text{,}\) whose limits of integration make it a single number.
    🔗
    🔗

    3. Practice: Indefinite Integrals.

    Use the power-rule formula from Exercise 1 to evaluate each indefinite integral below. (The sum rule and constant multiple rule you already know for definite integrals apply here too, term by term.)
    🔗

    (a)

    Find \(\displaystyle\int x^4\,dx\text{.}\)
    🔗
    🔗

    (b)

    Find \(\displaystyle\int x^{-3}\,dx\text{.}\)
    🔗
    🔗

    (c)

    Find \(\displaystyle\int \sqrt{x}\,dx\text{.}\)
    🔗
    🔗

    (d)

    Find \(\displaystyle\int (3x^2-5)\,dx\text{.}\)
    🔗
    🔗
    🔗

    4. Where the Pattern Breaks Down.

    The power rule to find antiderivatives of \(x^n\) works with \(n\ne -1\text{.}\) See what happens when \(n=-1\text{.}\)
    🔗

    (a)

    Try applying your general antiderivative formula to \(f(x) = x^{-1} = \dfrac{1}{x}\text{.}\) What goes wrong? Why can this formula not produce an antiderivative of \(1/x\text{?}\)
    🔗
    🔗
    🔗

    Remark 43. A New Kind of Function.

    The Fundamental Theorem of Calculus does not care whether a function is built from powers of \(x\text{.}\) It only asks for continuity. The function \(f(t)=1/t\) is continuous everywhere except at \(t=0\text{,}\) so on any interval avoiding \(0\text{,}\) it has an accumulation function, and that accumulation function must be an antiderivative of \(1/t\text{,}\) whether or not we have an algebraic formula for it in terms of powers. This gives us a way to create a genuinely new function, one we have not seen before, as an antiderivative of \(1/x\text{.}\) We name it the natural logarithm:
    \begin{equation*} \ln(x) = \int_1^x \frac{1}{t}\,dt\text{.} \end{equation*}
    🔗
    🔗

    5. Exploring \(\ln(x)\).

    We will be exploring \(\ln(x)\) based on its definition as an integral. In principle, we don’t actually know it should be a logarithm, just that it’s a valid antiderivative.
    🔗

    (a)

    What is \(\ln(1)\text{?}\) How is that value forced by the integral itself, with no computation needed?
    🔗
    🔗

    (b)

    The Fundamental Theorem of Calculus requires that the rate function must be continuous? Based on this, what must the domain of \(\ln(x)\) be?
    🔗
    🔗
    🔗

    Remark 44. Looking Ahead.

    You now have a genuinely new function, \(\ln(x)\text{,}\) defined directly by an integral rather than by any algebraic formula. In an upcoming activity we will explore its other properties.
