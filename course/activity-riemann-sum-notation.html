    Worksheet Setting Up Riemann Sums with Summation Notation
    

    Objectives

    • Write \(\Delta x = \frac{b-a}{n}\) for a partition of \([a,b]\) into \(n\) equal subintervals, as a formula in \(n\) rather than a number tied to one specific choice of \(n\text{.}\)
      🔗
      🔗
    • Write the \(k\)th right endpoint of the partition as \(x_k = a + k\Delta x\text{,}\) and check a general formula against known specific values from a previous example.
      🔗
      🔗
    • Use function composition to substitute \(x_k\) into simple algebraic functions.
      🔗
      🔗
    • Read and write summation notation \(\displaystyle\sum_{k=1}^n a_k\) as shorthand for "add up the terms \(a_1\) through \(a_n\text{,}\)" including expanding a short sum into its individual terms.
      🔗
      🔗
    • Assemble \(\Delta x\text{,}\) \(x_k\text{,}\) and \(f(x_k)\) into the full right Riemann sum
      \begin{equation*} \displaystyle\sum_{k=1}^n f(x_k)\,\Delta x \end{equation*}
      for a specific function and interval, for any number of subintervals \(n\text{,}\) without evaluating it.
      🔗
      🔗
    🔗
    Last class, we approximated \(\displaystyle \int_1^3 x^2 \, dx\) using left and right Riemann sums for \(f(x)=x^2\) on \([1,3]\) by hand, using a specific choice of \(n=4\) rectangles: you found the five partition points \(1, 1.5, 2, 2.5, 3\text{,}\) read off five function values from a table, and added up four rectangle areas. That works, but it required a fresh picture and a fresh table every time \(n\) changed. Today you’ll write down the pattern behind those numbers instead using formulas that work for any number of subintervals \(n\text{,}\) and a compact notation for "add these up" that doesn’t require writing out every single term.
    🔗
    To keep things manageable, we’ll set up only the right Riemann sum today (always using the right endpoint of each subinterval). The goal in every task below is to correctly write an expression. At this stage, we will not evaluate it, simplify it, or find its value as a formula in \(n\text{.}\)
    🔗
    Team Roles: Manager, Recorder, Spokesperson, and Reflector.
    🔗

    1. From \(n=4\) to Any \(n\).

    Recall the example from last class approximating \(\displaystyle \int_1^3 x^2 \, dx\text{,}\) the integral of \(f(x) = x^2\) on \([1,3]\text{.}\) With \(n=4\) subintervals, the width of each piece was \(\Delta x = 0.5\text{,}\) and the four right endpoints were \(x_1=1.5\text{,}\) \(x_2=2\text{,}\) \(x_3=2.5\text{,}\) \(x_4=3\text{.}\)
    🔗

    (a)

    In general, partitioning an interval \([a,b]\) into \(n\) equal-width subintervals gives each one a width of \(\displaystyle \Delta x = \frac{b-a}{n}\text{.}\) Using \(a=1\) and \(b=3\) from our example, but leaving \(n\) as a symbol, write \(\Delta x\) as an expression in \(n\text{.}\) Check that your expression gives \(0.5\) when \(n=4\text{.}\)
    🔗
    🔗

    (b)

    Each partition point is reached by taking \(k\) steps of size \(\Delta x\) away from the left endpoint \(a\text{.}\) That is, the \(k\)th right endpoint is \(x_k = a + k\,\Delta x\text{,}\) where \(k\) counts how many steps have been taken (so \(x_1\) is one step from \(a\text{,}\) \(x_2\) is two steps, and so on). Using \(a=1\) and your expression for \(\Delta x\) from the previous task, write \(x_k\) as an expression in \(k\) and \(n\text{.}\)
    🔗
    🔗

    (c)

    Check your formula: substitute \(n=4\) into your expression for \(x_k\text{,}\) then evaluate it at \(k=1\text{,}\) \(k=2\text{,}\) \(k=3\text{,}\) and \(k=4\text{.}\) Do you recover \(1.5\text{,}\) \(2\text{,}\) \(2.5\text{,}\) and \(3\text{?}\)
    🔗
    🔗
    🔗

    Definition 22 Summation Notation.

    The symbol \(\Sigma\) (capital Greek sigma) is a compact way to write "add up a list of terms that follow a pattern." The notation
    \begin{equation*} \sum_{k=1}^{n} a_k \end{equation*}
    means: start at \(k=1\) (the number written below \(\Sigma\)), evaluate the expression \(a_k\text{,}\) then repeat for \(k=2\text{,}\) \(k=3\text{,}\) and so on, up through \(k=n\) (the number written above \(\Sigma\)), adding every result together. Written out in full, it means the same thing as
    \begin{equation*} a_1 + a_2 + a_3 + \cdots + a_n\text{.} \end{equation*}
    Nothing here says how to find the value of that total — it’s just notation for which terms to add.
    🔗
    🔗

    2. Reading and Using Summation Notation.

    (a)

    Write out \(\displaystyle\sum_{k=1}^{5} (2k-1)\) as five separate terms (substituting \(k=1,2,3,4,5\) one at a time), then add them up.
    🔗
    🔗

    (b)

    Now use summation notation for something you’ve already computed. For \(f(x)=x^2\) on \([1,3]\) with \(n=4\text{,}\) recall \(\Delta x = 0.5\) and \(f(x_1)=2.25\text{,}\) \(f(x_2)=4\text{,}\) \(f(x_3)=6.25\text{,}\) \(f(x_4)=9\text{.}\) Write out \(\displaystyle\sum_{k=1}^{4} f(x_k)\,\Delta x\) as four separate terms (each a number, not a symbol), then add them up. Does your total match the right Riemann sum you found by hand last class?
    🔗
    🔗

    (c)

    Finally, replace the specific value \(n=4\) with a general \(n\text{.}\) Using your expressions for \(\Delta x\) and \(x_k\) from Exercise 1, write \(f(x_k)\) for \(f(x)=x^2\text{,}\) then assemble the full right Riemann sum \(\displaystyle\sum_{k=1}^{n} f(x_k)\,\Delta x\) for \(\displaystyle\int_1^3 x^2\,dx\text{,}\) entirely in terms of \(k\) and \(n\text{.}\) Do not simplify or evaluate — just set it up.
    🔗
    🔗
    🔗

    Remark 23 The General Recipe.

    Whatever the function, interval, or \(n\text{,}\) setting up the right Riemann sum for \(\displaystyle\int_a^b f(x)\,dx\) always follows the same four steps:
    1. Find the width of each subinterval: \(\displaystyle \Delta x = \frac{b-a}{n}\text{.}\)
      🔗
      🔗
    2. Write the \(k\)th right endpoint: \(x_k = a + k\,\Delta x\text{.}\)
      🔗
      🔗
    3. Substitute \(x_k\) into \(f\) to get \(f(x_k)\text{.}\)
      🔗
      🔗
    4. Assemble the sum: \(\displaystyle\sum_{k=1}^{n} f(x_k)\,\Delta x\text{.}\)
      🔗
      🔗
    The next three exercises are all the same four steps, applied to new functions.
    🔗
    🔗
