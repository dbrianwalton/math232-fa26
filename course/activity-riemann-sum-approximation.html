    Worksheet Approximating Area Under a Curve: An Introduction to Riemann Sums
    

    Objectives

    • Recognize that a curved function like \(f(x)=x^2\) is not built from flat or straight-line pieces, so the rectangle, triangle, and trapezoid formulas used so far don’t directly give its area.
      🔗
      🔗
    • From a table of function values, construct a region built only from horizontal and vertical segments (a staircase of rectangles) whose area can be computed exactly, as an approximation to the area under a curve.
      🔗
      🔗
    • Construct, from the same table, both the left-edge and right-edge staircase approximations (the left and right Riemann sums), and compute their total areas.
      🔗
      🔗
    • Determine, from the picture, which of the two approximations over-estimates and which under-estimates the true area, using the fact that the function is increasing.
      🔗
      🔗
    • Use a dynamic, slider-based visualization to observe the left- and right-sums converging as the number of subintervals grows, anticipating the definite integral as a limiting value.
      🔗
      🔗
    🔗
    So far, every rate function you’ve worked with has been piecewise constant or piecewise linear: built from flat pieces or straight-line pieces, so every region between the graph and the axis was a rectangle, a triangle, or a trapezoid, with an exact area formula ready to use. Today we start working with actual curved functions — functions like \(y = x^2\) — where no piece of the graph is a straight line, and none of those formulas apply directly.
    🔗
    You’ll build a way to approximate the area under a curve instead, using only tools you already have: rectangles. As always, the goal is to understand why the method works, not just to get a number.
    🔗

    1. Sketching Your Own Approximation.

    The table below shows the value of \(f(x) = x^2\) at five values of \(x\text{,}\) evenly spaced from \(x=1\) to \(x=3\text{.}\)
    🔗
    \(x\) \(1\) \(1.5\) \(2\) \(2.5\) \(3\)
    \(f(x) = x^2\) \(1\) \(2.25\) \(4\) \(6.25\) \(9\)
    These same five points are plotted below, along with the curve \(y=x^2\) itself, shown dashed just for reference — imagine it isn’t there when you answer the next task.
    🔗

    (a)

    On the graph above, using only horizontal and vertical segments, sketch a region using these five points whose exact area you could compute using rectangles to approximate the area under the curve from \(x=1\) to \(x=3\text{.}\)
    🔗
    🔗

    (b)

    Why can you compute the exact area of the shape you just drew, even though you can’t (yet) compute the exact area under the curve itself?
    🔗
    🔗
    🔗

    2. Left and Right Riemann Sums.

    Below are two more copies of the same five points and reference curve. On each one you’ll build a staircase a specific way: on every subinterval between two consecutive points, draw a horizontal segment at one of the two heights available, then close it off with vertical segments down to the axis.
    🔗

    (a)

    On the LEFT graph: on each of the four subintervals, use the height of the point at its left end (so, for example, the piece from \(x=1\) to \(x=1.5\) gets height \(f(1)=1\)). Draw the resulting staircase, then add up the four rectangle areas to find its total area.
    🔗
    🔗

    (b)

    On the RIGHT graph: on each subinterval, use the height of the point at its right end instead (so the piece from \(x=1\) to \(x=1.5\) gets height \(f(1.5)=2.25\)). Draw the resulting staircase, then add up its four rectangle areas.
    🔗
    🔗

    (c)

    Compare your two totals. Which staircase leaves gaps under the curve (an under-estimate), and which one pokes out above the curve (an over-estimate)? Explain how you can tell from the picture, using the fact that \(f(x)=x^2\) is increasing on \(1 \le x \le 3\text{.}\)
    🔗
    🔗
    🔗

    Remark 40 Naming What You Just Built.

    Each of your two staircases is an example of a Riemann sum: an approximation to the area under a curve built by partitioning an interval into subintervals, choosing one height on each piece, and adding up the resulting rectangle areas. What you built are called the left Riemann sum (using left-edge heights) and the right Riemann sum (using right-edge heights), each with \(n=4\) subintervals.
    🔗
    🔗

    3. More Rectangles, and a Limit.

    Four rectangles was a choice, not a requirement. Open the Riemann sum visualization linked below, which plots \(y=x^2\) together with a slider for \(n\text{,}\) the number of subintervals, and reports the left- and right-Riemann sum totals as you change it.
    🔗
    Riemann Sum Visualization (Desmos)
    🔗

    (a)

    Set the slider to \(n=4\) on the interval \([1,3]\) and confirm the left- and right-sum values match what you computed by hand in Exercise 2.
    🔗
    🔗

    (b)

    Now increase \(n\text{.}\) Try \(10\text{,}\) then \(50\text{,}\) then as large as the tool allows. What happens to the left-sum value and the right-sum value as \(n\) grows?
    🔗
    🔗

    (c)

    Both sums appear to approach a single number as \(n\) gets larger and larger. That number is, by definition, the exact value of \(\int_1^3 x^2\,dx\text{.}\) Record the value you observe. Later in the course, the Fundamental Theorem of Calculus will let you find this number directly, without taking any limit by hand.
