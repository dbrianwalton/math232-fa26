Definition 58 The Number \(e\) and Real Powers.

The natural base \(e\) is that number with \(\ln(e)=1\text{.}\)
🔗
For every real number \(p\text{,}\) the power \(e^p\) is the number \(N\) with
\begin{equation*} e^p = N \quad \Leftrightarrow \quad \ln(N)=p\text{.} \end{equation*}
More generally, if \(b \gt 0\text{,}\) the power \(b^p\) is the number \(N\) with
\begin{equation*} b^p = N \quad \Leftrightarrow \quad \ln(N)=p\ln(b)\text{.} \end{equation*}
That is, we define powers so that the power rule for logarithms is valid.
🔗
The natural exponential function is \(\exp(x)=e^x\text{,}\) and the exponential function with base \(b\) is \(\exp_b(x)=b^x\text{.}\)
